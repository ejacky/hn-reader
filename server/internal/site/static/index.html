What it does

Four things, done well. Nothing else is bolted on.

Summaries where you already read

A [summary] link next to every title, and [summarize] on every comment. Click, get the point in three lines, decide in one second.

Highlights that learn

The extension notices what you open, favorite and read closely, then marks the stories you are likely to care about with an orange border.

Nothing to configure

Cloud mode creates an anonymous account for you. No API key, no server, no sign-up form — 50 summaries a month, free, from the first click.

Yours to delete

No name, no email. Export your data or wipe the account from the popup. Want it fully local? Run the open-source server yourself.

How it works

Three steps. The third one is just reading.

  1. 01

    Install the extension

    From the Chrome Web Store. Works in Chrome and Edge; it only runs on news.ycombinator.com.

  2. 02

    Open Hacker News

    Summaries appear inline on the list and comment pages. Nothing else about the site changes.

  3. 03

    Click, and read

    Your clicks teach the model what you care about. The highlighting gets sharper every day you use it.

Privacy, in one screen

A reading tool should not need your identity. This one does not ask for it.

  • An anonymous random token is your account — no name, no email, no password.
  • Article and comment text goes to the LLM provider only to generate the summary you asked for.
  • Export everything, or delete the account and its data, from the extension popup.
  • Prefer it fully local? The server is open source — run it on your own machine with your own key.
  • No ads, no data sales, no training on your reading.

Questions

Is this affiliated with Hacker News or Y Combinator?

No. HN Reader is an independent extension that runs on top of news.ycombinator.com. It is not endorsed by Y Combinator.

Do I need an OpenAI key?

No. Cloud mode is included: the extension gets an anonymous token and calls our service. If you would rather use your own model, switch to local mode and point the extension at your own server.

Which browsers are supported?

Chrome and Edge, both Manifest V3. Firefox is not supported yet.

What happens when the 50 summaries run out?

Summaries you already generated keep opening from cache. The quota resets every month, and you can keep going immediately by switching to local mode with your own key.

Where is my reading data stored?

Reading signals and generated summaries live on our PostgreSQL in Shanghai until you delete them. Article text is not stored long-term. Full details are in the privacy policy.

Can I self-host it?

Yes. The backend is Go with SQLite for local mode; build it from the repository and the extension will talk to http://localhost:8080.
