## 本次提交方式

- 提交时只提交了**默认英文**元数据，中文（中国）条目没有填详细描述。
- 关键修复不依赖后台输入：商店的摘要由软件包自动读取（`_locales/<locale>/messages.json` 的
  `extDescription`），1.3.2 的 `zh_CN` 已经是中文，所以中文条目的摘要本身是对的。
- 提交时没填正文的中文条目会回落成默认语言正文，即「中文摘要 + 英文正文」。这不算错，只是一致性弱一点；
  当时审核中改列表信息可能让审核重排，所以留到过审之后补；**上线后核对，中文页已有完整中文描述**。
