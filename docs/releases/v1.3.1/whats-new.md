# v1.3.1 — 新版本说明

Chrome Web Store 的「What's new in this version」，中英两版可直接粘贴。

## English

```
HN Reader 1.3.1

• The extension no longer requests access to any domain other than Hacker News
  and the HN Reader cloud API — the leftover staging host is gone.
• English interface with 中文 kept: the UI follows your browser language, and you
  can override it in Settings.
• Summary language follows the interface unless you have chosen one.
• Preload status is visible per story: preloaded, or failed with a reason.
• Summaries and preloads time out after 20 seconds instead of hanging.
```

## 中文

```
HN Reader 1.3.1

• 扩展现在只申请访问 Hacker News 与 HN Reader 云服务两个域名，移除了此前遗留的测试域名权限。
• 界面支持英文，中文完整保留：默认跟随浏览器语言，也可在设置里手动切换。
• 摘要语言默认跟随界面语言，你手动选过的语言保持不变。
• 每条文章的预加载状态可见：已预加载，或失败原因。
• 摘要与预加载请求 20 秒超时，不再挂在失去响应的连接上。
```
